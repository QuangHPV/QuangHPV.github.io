# Portfolio site (Astro)

* Never use the middle dot character (Unicode U+00B7) anywhere in this project, in text or code. Use a comma, a pipe, or a new line instead. Check with: grep -rn $'\xc2\xb7' src
* All site text lives in src/content.ts. Keep it short, honest, first person, plain words.
* Style targets: Long, Shailes, Giang Son, Hoang (layout, simplicity, colour). Do not copy Trung's site. Do not use Instrument Serif or Geist.
* Sans-serif only. Elegant, not extravagant. Light mode by default, dark mode optional.
* Keep dependencies at zero beyond Astro. No UI libraries.
* TODO.md holds open items that must not appear on the site.
